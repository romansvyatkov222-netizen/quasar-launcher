# Выпуск новой версии лаунчера (просто и по шагам)

Весь цикл: поднял версию → тег → GitHub Actions собрал → у игроков модалка обновления.

## Шаг 1. Подними версию

Открой `launcher/src-tauri/Cargo.toml` и поменяй версию:

```toml
version = "0.3.0"   # была 0.2.0
```

Версия должна быть **больше** предыдущей (сравнение по числам: 0.2.0 < 0.3.0 < 1.0.0).

## Шаг 2. Закоммить и тегируй

```bash
git add launcher/src-tauri/Cargo.toml launcher/src-tauri/Cargo.lock
git commit -m "v0.3.0"
git tag v0.3.0
git push origin main v0.3.0
```

Важно: тег **всегда** в формате `v` + номер (`v0.3.0`, `v1.2.5`), иначе Actions не запустится.

## Шаг 3. Жди сборку (~7–10 минут)

Смотри прогресс: https://github.com/romansvyatkov222-netizen/quasar-launcher/actions

Когда галочка зелёная — релиз готов:
https://github.com/romansvyatkov222-netizen/quasar-launcher/releases
(там лежит `QuasarLauncher.exe`, собранный из твоего кода)

## Шаг 4. Ничего не делай — всё само

У игроков при следующем запуске лаунчера:

1. Лаунчер спрашивает бэкенд: «какая последняя версия?»
2. Видит 0.3.0 вместо своих 0.2.0 → модалка **«Доступно обновление»**
3. Игрок жмёт «Обновить» → прогресс-бар скачивания
4. Лаунчер сам заменяет exe и перезапускается уже новой версией

Если игрок нажал «Позже» — модалка покажется при следующем запуске.

## Если сборка упала (красный крестик)

1. Открой упавший run в Actions → прочитай, на каком шаге упало
2. Чинить не нужно срочно: тег можно перевыпустить:
   ```bash
   git tag -d v0.3.0
   git push origin :refs/tags/v0.3.0
   # ...исправил...
   git tag v0.3.0
   git push origin v0.3.0
   ```

## Что меняется на сервере — НИЧЕГО

Бэкенд на VDS трогать не нужно: он лишь транслирует «какая версия последняя»
из GitHub Releases. Токен GitHub уже лежит в `.env` на VDS.

## Частые вопросы

**Q: Бэкенд тоже нужно обновлять?**
Только если менял код бэкенда (`backend/`). Лаунчер и бэкенд — независимые части.

**Q: Игрок во время обновления запустил игру?**
Ничего не сломается: обновление заменяет только exe лаунчера, Minecraft и его
файлы не затрагиваются.

**Q: Можно ли откатить версию?**
Да: создай релиз со старым exe (через web-интерфейс, кнопка Draft new release),
но у игроков с более новой версией откат не сработает — сравнение только «вверх».
